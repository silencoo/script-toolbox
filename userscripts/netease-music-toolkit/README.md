# NetEase Music Toolkit

This directory keeps a navigable snapshot of Cinvin's MIT-licensed
`myuserscripts` NetEase Music userscript. The script supports downloads, cloud
transfer and matching, playback quality controls, metadata handling, and other
music.163.com enhancements.

## Install

Install `netease-music-toolkit.user.js` with a userscript manager after
reviewing its permissions and remote dependencies. The snapshot grants broad
network, cookie, download, and page-injection capabilities because those are
required by its feature set. Its original `@downloadURL` and `@updateURL` still
point to GreasyFork, so an installed copy may update independently of this
repository.
