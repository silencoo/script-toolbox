## 123网盘妙传功能实现原理总结

### 1. 核心概念
123网盘的"妙传"功能实际上是一种**秒传**技术，通过文件的唯一标识符（etag）和文件大小来实现快速转存，无需重新上传文件内容。

### 2. 技术实现架构

#### 2.1 核心组件
- **PanApiClient**: 123云盘API通信类
- **TableRowSelector**: 文件选择管理类  
- **ShareLinkManager**: 秒传链接生成/转存类
- **UiManager**: 用户界面管理类

#### 2.2 关键数据结构
每个文件包含以下关键信息：
```javascript
{
    fileName: "文件名",
    etag: "文件唯一标识符", 
    size: "文件大小",
    type: "文件类型(0=文件,1=文件夹)",
    fileId: "文件ID"
}
```

### 3. 妙传链接生成流程

#### 3.1 文件信息收集
1. **获取文件列表**: 通过API `/b/api/file/list/new` 获取当前目录文件
2. **递归扫描**: 对选中的文件夹进行递归扫描，获取所有子文件
3. **提取关键信息**: 提取每个文件的 `etag`、`size`、`fileName` 等

#### 3.2 链接构建
```javascript
// 链接格式: 123FLCPV2$公共路径%etag#size#path$etag#size#path...
const shareLink = `${COMMON_PATH_LINK_PREFIX_V2}${commonPath}%${shareLinkFileInfo}`;
```

#### 3.3 编码优化
- 支持Base62编码压缩etag，减少链接长度
- 提取公共路径，避免重复存储相同路径前缀

### 4. 妙传链接解析与转存流程

#### 4.1 链接解析
1. **解析链接格式**: 提取公共路径和文件信息列表
2. **Base62解码**: 将压缩的etag转换回十六进制格式
3. **路径处理**: 重建完整的文件路径结构

#### 4.2 文件夹创建
1. **创建公共路径**: 根据 `commonPath` 创建基础文件夹结构
2. **递归创建子目录**: 为每个文件的相对路径创建对应文件夹
3. **记录文件夹ID**: 维护文件夹路径到ID的映射关系

#### 4.3 文件转存
```javascript
// 关键API调用
const response = await this.sendRequest('POST', '/b/api/file/upload_request', {}, JSON.stringify({
    driveId: 0,
    etag: fileInfo.etag,        // 文件唯一标识
    fileName: fileInfo.fileName,
    parentFileId: parentFileId,
    size: fileInfo.size,
    type: 0,                    // 文件类型
    duplicate: 1                // 允许重复
}));
```

### 5. 核心技术原理

#### 5.1 秒传机制
- **etag唯一性**: 123网盘为每个文件生成唯一的etag标识符
- **服务器端去重**: 通过etag+size验证文件是否已存在
- **Reuse标志**: 服务器返回 `Reuse: true` 表示文件已存在，可直接创建引用

#### 5.2 文件指纹算法
- 123网盘使用类似MD5/SHA的哈希算法生成etag
- 相同内容的文件具有相同的etag，无论文件名如何
- 通过etag+size的组合确保文件唯一性

#### 5.3 批量处理优化
- **分批请求**: 大量文件分批处理，避免API限制
- **延时控制**: 在请求间添加适当延时，避免触发频率限制
- **进度跟踪**: 实时显示处理进度和状态

### 6. 安全与限制

#### 6.1 权限验证
- 需要有效的 `authorToken` 和 `LoginUuid`
- 必须登录123网盘账户才能使用

#### 6.2 文件访问控制
- 只能转存用户有权限访问的文件
- 受123网盘存储配额限制

### 7. 优势特点

1. **极速转存**: 无需重新上传，秒级完成文件转存
2. **存储效率**: 相同文件只存储一份，节省存储空间  
3. **批量操作**: 支持大量文件的批量转存
4. **路径保持**: 完整保持原始文件夹结构
5. **跨用户共享**: 通过妙传链接实现文件快速分享

这个妙传功能本质上是一种基于文件内容指纹的去重和引用技术，通过123网盘后端的文件去重机制，实现了文件的快速转存和分享。
