# Sehuatang Search Enhancer

A Userscript to enhance the search result pages on Sehuatang (sehuatang.org).

## Features

### 🛠 Floating Sorting Tool
A convenient floating panel on the right side of the page allows you to sort current search results instantly without refreshing or re-searching (avoiding search frequency limits).

### 📊 Client-Side Sorting
Sort search results by:
- **Replies**: Find the most discussed threads.
- **Views**: Find the most popular threads.
- **Post Date**: Sort by newest/oldest.
- **File Size**: (Experimental) Parses file size from title/content.
- **Quota**: (Experimental) Parses download quota costs.

### ✨ Smart Highlighting
- **Auto-Highlight**: Automatically highlights "Hot" threads based on configurable thresholds (Replies/Views).
- **Custom Thresholds**: Set thresholds to Low, Medium, High, or Auto.

### 🔍 Filtering
- **Filter "Request" Threads**: One-click option to hide "求片" (Request) threads from results to focus on resources.

### ⚙️ Automation
- **Auto-Sort**: Can be configured to automatically apply your preferred sorting method when the page loads.
- **Auto-Highlight**: Automatically highlights hot threads on load.

## Usage

1. Search for something on Sehuatang.
2. Use the floating "🔧" icon or panel on the right.
3. Click buttons to sort or filter.
4. Settings are saved automatically for future visits.

## Configuration
All settings (Auto-sort preference, Highlight thresholds, etc.) are available directly in the floating panel.
