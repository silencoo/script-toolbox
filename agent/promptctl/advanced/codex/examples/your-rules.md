# Codex Instructions Example

Use this file only as a neutral starting point. Review and adapt it before
deploying it with `--file`.

- Read the repository's documentation before changing code.
- Preserve existing user configuration unless the task explicitly requires a
  change.
- Prefer small, reviewable edits and report the verification performed.
- Never put credentials, tokens, cookies, or private runtime state in an
  instruction file.
- Describe the exact target before a risky or irreversible operation.
